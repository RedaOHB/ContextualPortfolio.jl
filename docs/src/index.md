# ContextualOptimization.jl 
* A julia package for contextual optimization and backtesting * 

## Overview
```ContextualOptimization.jl``` is a julia package for portfolio optimization that incorporate external factors (e.g., market conditions, economic indicators) into the decision-making process. The package supports multiple optimization models including mean-variance, CVaR, and robust optimization. It provides comprehensive tools for performance evaluation and backtesting.
